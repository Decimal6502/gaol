# Icons

PWA icons should be original assets.

Do not use official FFXI icons or game assets.

Recommended sizes:

- icon-192.png
- icon-512.png
- maskable-icon-192.png
- maskable-icon-512.png

Suggested design direction:

- abstract tactical board
- fantasy crystal motif
- dark navy / gold / stone gray
- no text
- readable at small size
