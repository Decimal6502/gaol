# Privacy Policy

Gaol Tactician is a static web app that works in your browser. It has no backend server for user data.

## Data stored in localStorage

The app may store the following editable data in your browser's `localStorage`:

- display names
- job availability data
- current battle plan data
- app settings

This data stays in the browser storage for the device and browser profile you use.

## No developer-server upload

The app does not send display names, job availability data, plan data, backup data, copied text, or generated images to a developer server.

The app is not connected to FINAL FANTASY XI, PlayOnline, Windower, Ashita, or the game client.

## Manual exports

Text preview, PNG download, and JSON backup files are generated locally in the browser.

Text and PNG exports include only the current plan. They do not include the full display-name/job-availability database or historical plans. Anonymous labels are used by default unless you explicitly enable display names.

JSON backups may include display names, job availability data, battle plans, and app settings. Store JSON backups only in trusted locations.

## Personal information

Do not enter real names, email addresses, phone numbers, Discord IDs, X/Twitter IDs, LINE IDs, addresses, or other contact information.

Use short display names or aliases that are safe to store locally and export manually.
